
## Algorithms - Searching

In **IntelliJ IDEA**, create a **New Project** called **Search**.

In the **src** folder create a Java class file called `Search.java` with the following methods:

1. Write a method `int linearSearch(int[] values,  int n)` -, that searches for the integer `n` in the array and **returns** the **index** where the item is first found *(searching left to right)* or -1 if `n` is not in the array.

2. Write a method `int linearSearch(String text,  char c)` -, that searches for the character `c` in the string and **returns** the **index** where the item is first found *(searching left to right)* or -1 if `c` is not in the string.

3. Write a method `int linearSearch(int n,  int d)` -, that searches for the digit `d` in the number `n` and **returns** the number of times it is found.

4. Write a function `int binarySearch(int [] values, int n)`, that searches for the integer `n` in the array `values` and **returns the index** where the item is found or -1 if `n` is not in the array. *Assume the array is sorted from lowest to highest values .*

5. Write a function `int binarySearch(char [] letters, char c)`, that searches for the character `c` in the array of characters `letters` and **returns the index** where the item is first found *(searching left to right)* or -1 if `c` is not in the array. *Assume the array is in alphabetical order .*
